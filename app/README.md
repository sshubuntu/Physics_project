# EMI Simulation Console

Flet-приложение для записи демонстрации эксперимента без подключения к Arduino, датчикам и `iperf3`.

## Что делает

- Запускает 30-секундную симуляцию кнопкой.
- Показывает, как кабель подводится к источнику помех: расстояние уменьшается с 20 см до 5 см.
- Обновляет графики уровня ЭМП, throughput, packet loss, delay и jitter.
- В контрольных точках использует значения из отчета:
  - 0 с: без помех;
  - 15 с: ЭМП-режим A;
  - 30 с: ЭМП-режим B.
- Сохраняет CSV в `app/results/simulated_emi_session.csv`.

## Запуск

```bash
python tester_control_flet.py
```

Для записи видео нажмите `Запустить 30-секундную симуляцию` и снимайте экран приложения.
