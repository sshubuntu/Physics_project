# EMI Quantum Console (Flet)

Приложение управляет тестером электромагнитных помех, запускает сетевые тесты и сохраняет синхронизированные результаты в CSV.

## Что умеет

- Подключение к тестеру через COM-порт.
- Пошаговое сканирование частоты с заданным шагом.
- Запуск `ping`, `iperf3`, `speedtest`.
- Сохранение результатов в CSV с временной меткой.
- Построение графика по выбранным колонкам CSV прямо в интерфейсе.

## Требования

- Python 3.10+
- Пакеты:
  - `flet`
  - `pyserial` (для COM-подключения к тестеру)
- Внешние утилиты в `PATH`:
  - `iperf3`
  - `speedtest`

Установка:

```bash
pip install flet pyserial
```

## Подключение тестера

1. Подключите тестер по USB/UART.
2. Узнайте COM-порт в Windows (например, `COM3`).
3. Откройте приложение и задайте:
   - `COM-порт тестера` (пример: `COM3`)
   - `Скорость порта` (пример: `115200`)
4. Проверьте сеть:
   - `IP iperf3-сервера` (должен быть доступен сервер `iperf3 -s`)
   - `Хост для ping` (например `8.8.8.8`)

## Протокол обмена с тестером

На каждом шаге приложение отправляет в порт команду:

```text
SET FREQ=<частота_Гц> DUTY=<заполнение_%> DUR=<длительность_с>
```

Ожидаемый ответ датчика (любой из форматов):

- `E=12.4;B=0.003`
- `{"E":12.4,"B":0.003}`

Если у вашего устройства другой протокол, измените формат в `tester_control_flet.py` (методы отправки команды и `_parse_sensor_line`).

## Запуск

```bash
python tester_control_flet.py
```

## Работа с графиком CSV

1. Укажите путь к CSV в поле `CSV для графика`.
2. Выберите колонку для оси `X`.
3. Выберите колонку для оси `Y`.
4. Нажмите `Построить график из CSV`.

Типичные пары:

- `X=frequency_hz`, `Y=packet_loss_percent`
- `X=field_v_m`, `Y=iperf_mbps`
- `X=field_v_m`, `Y=ping_avg_ms`

## Формат CSV

Файл содержит ключевые столбцы:

- `timestamp_utc`
- `frequency_hz`, `duty_percent`, `duration_s`
- `field_v_m`, `field_t`
- `ping_avg_ms`, `packet_loss_percent`
- `iperf_mbps`
- `speedtest_download_mbps`, `speedtest_upload_mbps`
- `raw_sensor_line`, `notes`

## Быстрая диагностика

- Пустые поля `field_v_m/field_t`: проверьте COM-порт и протокол датчика.
- Нет `iperf_mbps`: проверьте доступность `iperf3` сервера.
- Нет данных `speedtest`: проверьте установку `speedtest` и доступ в интернет.
- График пустой: убедитесь, что выбранные столбцы содержат числовые значения.
